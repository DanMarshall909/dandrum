## Required correction R1: preserve the old-epoch reset oracle

File/symbol: `src/trigger-host/src/runtime.rs`, `admission_tests::successful_state_publication_retires_queued_notes_and_reset_cannot_settle_old_generation_commands`, especially lines 1406-1423. Requirement: preserve existing behavior/regression protection when extending the fixture; agentic-delivery completion review dimension 3 and project coverage/TDD instructions.

At the base, a real sequenced UI parameter (sequence 10) remains queued when successful restore advances the epoch. `audio.reset()` consumes that obsolete command, and the subsequent `(0, false, ...)` settlement assertion rejects an implementation that accidentally acknowledges it. In the candidate, `flush_parameters(&[])` consumes all eight obsolete scalars before reset. The test explicitly asserts `reset().discarded_events == 0`, so the unchanged assertion labelled “reset cannot acknowledge an old epoch's UI command” no longer exercises that rule. A regression removing the epoch comparison in `AudioState::reset` would no longer be rejected by this witness.

Root highlighted this possibility during review; I independently compared HEAD and candidate fixtures and searched the remaining reset tests. `tests/state.rs` drains old queued input with process before reset, while parameter and reconfiguration cancellation tests exercise current-epoch input. I found no replacement witness for reset consuming an obsolete nonzero sequence. The new flush discard test is useful but cannot substitute for reset's independent policy.

Required outcome: retain the new full stale-scalar-prefix flush proof and separately restore a real obsolete nonzero UI command reaching reset. Assert that reset actually discards the retained entry, does not count it as a cancelled current command, and preserves the restored scalar/zero settlement and reset cause. This can be an independent fixture or another real queue/restore cycle; no production hook or manual epoch injection is needed. Rerun affected and final owner checks, refresh source-bound evidence, freeze the whole candidate and return it to this same reviewer. Mutation remains excluded; a mutation run is not requested.
