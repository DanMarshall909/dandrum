## Contract

- `PreparedRuntime::new(prepared, configuration)` constructs graph/scratch off audio, requires preparation sample rate/block to match, mono bound control inputs and exactly one stereo audio output, and rejects unsupported realtime root schedules by off-audio probe/reset. Engine preparation already rejects unsupported poly child schedules recursively (preparation.rs:1655ff).
- `runtime_handoff(initial,event_capacity)` returns `Result<(RuntimeControl,RuntimeAudio),RuntimeError>`. Event capacity is 1..=1024 and no more than half engine pending event capacity; this reserves both control/host sources without overflow. For the tested16-frame graph, source capacity limit is64.
- Control `offer(next)` returns rejected ownership on incompatible configuration/surface or busy handoff. One replacement is in flight until `reclaim()` returns its retired runtime off audio. Audio reserves retirement storage before taking a candidate. Even dropping control first leaves retired ownership inside the audio endpoint until returned and destroyed off audio.
- Control `try_send(ControlEvent)` bounds note/scalar activity. Parameter indices are prepared root control-input order; adapters map stable root names via `parameter_index`. `parameter_value` reads f64 atomics. `take_feedback` returns parameter index/value/sample offset. Queue backpressure is explicit.
- Audio `process(left,right)` and `process_events(left,right,&[TimedEvent])` validate complete shape/count/ranges/offset ordering before mutation and then swap at a block boundary. Queue events occur at offset0; host events retain block offsets. ProcessReport exposes swapped/admission_closed/parameter_updates/dropped_feedback. Overflow preserves latest atomic scalar values for main-side recovery.
- `ActivationHost` implementation prepares first, reserves activation slot, closes atomic admission and waits off audio for the admitted callback guard to finish. Held lease makes arriving callbacks silent and non-consuming. Cancellation reopens old state; publish is allocation-free and infallibly makes candidate available before reopening admission. Control-side waiting only; callback guard uses atomics and no Arc cloning/destruction.
- `reset` clears pre-reset queued activity and DSP/voices, retaining applied scalar values and admitted replacement. The audio endpoint must be returned off audio before destruction; adapters own that stop/return lifecycle.

## Refactor decisions

Production: reserved safe rtrb chunks replace impossible-full callback fallback; shared event validation is reused across bounded sources; audio state is split from admission gate so Rust borrowing allows an RAII atomic guard without Arc clones; constructor establishes immutable renderability/frame-size invariant before callback. No further module extraction is justified for this single ownership boundary.
Tests: shared real planar-session fixture retains independent signed sample expectations; table-driven invalid inputs share one contract; distinct offset, rollback, reset, overflow and teardown tests remain because each adds a different invariant. Allocation audit remains separate from musical correctness and has its own positive and negative calibration.
