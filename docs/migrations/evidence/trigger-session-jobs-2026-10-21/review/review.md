## Architecture, authority, ownership and failure atomicity

No new dependency, core frontend type, unsafe block, queue or alternate session journal is introduced. `admitted_context` is the single sealing boundary: private Arc identity binds the connection, retained ID/command equality binds the admitted action, and snapshot uses the connection's real native attachment. A caller replacing public fields cannot manufacture that capability. Private completion Arc plus native ID binds the exact outstanding preparation. Rust moves prevent duplicate owned completion submission; rejection returns the original value. Heap/reference-count operations remain on preparation/control paths.

Service exclusively borrows the controller/runtime. Its private in-flight readiness cannot become occupied by another control producer between check and activation; audio can return retirement, but cannot create a control-owned second activation. Reclamation happens off audio before the readiness check. Session complete_mapping deliberately retains activation failures terminally, so deferring before that call is essential and directly tested. Existing Session installation obtains an activation lease before replacing accepted state, and publication ends gestures only on successful outcome. Reserved End capacity prevents cleanup loss without blocking audio. Next JavaScript-safe generation is checked before consuming/publishing the completion. Errors/defer retain old state, generation, history, gesture and scalar settlement; known outcomes return their historical snapshot, and failures do not fabricate one.

Dropped preparation, worker panic, automatic wake, controller shutdown and eventual delivery to a browser are explicitly outside this manual component. Their absence is a remaining product task, not an implied guarantee or a hidden completion claim. Native undo retries after changed history must query retained status; this API does not promise blind undo replay.

## Simpler alternatives and refactoring

Directly completing into Session while Busy is smaller but demonstrably wrong: Session terminally records activation failure and consumes the prepared work. A generic actor/queue framework now would expand accepted scope and obscure the one-job invariant. The enum and owned wrappers are proportionate; the private Arc is a cheap identity token with a real foreign-controller oracle. Keeping only native IDs would allow same-ID cross-controller misrouting. Separate copies of gesture retirement would duplicate reserved-capacity arithmetic; the small shared helper improves that boundary without extracting a module requiring new coverage. Exposing raw Session mutability or manufacturing private state for coverage would weaken the design. Making all AdmittedRequest fields private could be a future API cleanup, but current shared admission validation already enforces authority and avoids unrelated API churn. No materially better in-scope alternative requires a correction.
