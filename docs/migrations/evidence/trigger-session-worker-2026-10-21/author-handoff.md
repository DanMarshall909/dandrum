## Implemented boundary

Explicit `start_session_worker(Arc<dyn SessionServiceWake>)` installs one instrument-owned thread. Capacity-one synchronous channels transfer only owned preparation/completion offaudio. Structural admission automatically sends newly admitted work before acknowledging. Public manual take cannot steal it; manual controllers retain their landed take/submit/service compatibility. Duplicate install or install with active manual preparation rejects. Failed OS spawn cannot alter the session/cursor because it occurs before worker installation or admission; that OS failure path was inspected, not executed.

Only controller service drains at most one completion and performs existing bounded reclamation/publication. Completion wake occurs after insertion, independently of editor lifetime. Busy keeps Ready and emits no self-wake; the format facade must forward actual RuntimeAudio ProcessReport.swapped to another main callback. Tests use a bounded scheduler stand-in with the real report, not CLAP calibration. PhantomData<Rc<()>> is a zero-sized !Send/!Sync marker; maintained compile-fail move law has genuine RED then E0277 GREEN. The constructing thread is the control owner; native facade must construct it on actual host main.

Explicit shutdown and RAII share one idempotent shutdown operation: close request sender, join, then drop pending/undeliverable result offaudio. Worker field precedes session/runtime fields. Editor detach never stops it. A stopped installed owner rejects new work before native admission, service returns SessionWorkerUnavailable, active status returns unavailable rather than permanently running or fabricated native failure. Manual shutdown with no installed worker is an explicit no-op. There is no restart of a stopped installed worker and no promise to cancel arbitrary blocking file I/O.

Unexpected internal termination is fatal unavailable. Worker exit guard disconnects result sender BEFORE unwind wake, so main detects disconnect even if JoinHandle::is_finished has not yet flipped. Worker owns no Session/controller/runtime. No panic-catching job recovery or invented terminal outcome. Wake contract requires nonblocking/nonpanicking scheduling, never inline service. Internal-panic, OS-spawn failure and invariant-error branches remain unexercised; no arbitrary panic/invalidation/preparation-executor seam was introduced.
