Main keeps one persistent controller behind RefCell and the sole parked RuntimeAudio in Cell. Activation restores the owned endpoint on every Result failure, services/reconfigures the same pair, and moves it to the audio owner only on success. Deactivate restores it without borrowing the controller. Every host stream callback runs outside controller borrows. Flush uses the existing core scalar-prefix law.
