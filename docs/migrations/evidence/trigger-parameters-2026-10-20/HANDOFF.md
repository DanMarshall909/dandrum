## Accepted scope and ownership

This implements the format-neutral public-parameter/gesture/feedback portion of task 2.4. Task 2.4 stays OPEN. There is no v2 save/load, atomic document/resource/value restore, restore epoch, CLAP automation emission, live React wiring, WebView, or DAW acceptance claim.

ParameterController privately owns TriggerHost, RuntimeControl and EditorProtocol. `open` returns the controller and its matching RuntimeAudio, preventing callers from pairing two arbitrary same-shaped instances. Only immutable alias metadata is cached; actual physical scalar values remain runtime atomics. The controller exposes the session read-only, so aliases stay frozen for this tracer. Native Attachment validation prevents same-ID objects from a foreign session authorizing a write. Later state replacement must validate/freeze the alias catalogue before publication.

The 23 public IDs/order derive from preset_surface aliases; root_index maps independently to the prepared runtime's root ports. UI commands are normalized; AutomationEvent values and runtime values are physical. Begin reserves room for End, including detach cleanup; a standalone Value synthesizes Begin/Value/End. Peek/ack retains automation until a format adapter reports host acceptance. Runtime and automation admission are checked together before either is published, relying on exclusive producer ownership and a consumer that can only free runtime space.

Sequence is the last SETTLED UI value command: either applied or canceled by reset. Ordinary pending UI writes keep the previous sequence. One packed AtomicU64 pairs settlement sequence and reset_cancelled cause (latest settlement cause, not cumulative history). Audio writes a scalar before a Release settlement; main reads settlement with Acquire before scalar loads. Newer racing scalar values can only carry a conservative old acknowledgement; reads never close callback admission. This is not a coherent whole-state save snapshot; that belongs to the later state criterion. Host feedback stores its contemporaneous settlement metadata and sample offset, so old feedback cannot acknowledge newer queued UI work.

Reset preserves old applied scalar values and existing queued-work discard semantics. ResetReport reports cancellation counts and admission_closed if a publication lease prevents reset. A canceled accepted command advances settlement with explicit cancellation, allowing the adapter to request a callback and reconcile rather than leaving the frontend permanently below its admitted sequence. No document generation bump. JS handling of this additive metadata is later wiring.
