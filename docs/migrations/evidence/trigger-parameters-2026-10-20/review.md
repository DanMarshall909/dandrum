Critical correctness assessment

The callback is the sole writer of scalar values and packed settlement. For an applied UI command it stores its physical scalar, then Release-stores(sequence<<1). Reset drains at most the fixed event capacity, tracks the last canceled UI command in FIFO order, resets DSP, then Release-stores(sequence<<1|1). Main loads this single packed atomic with Acquire before reading scalars. Observing settledN therefore observes the scalar stores precedingN; racing newer values may carry only a conservative older acknowledgement. Sequence and cancellation cause cannot tear. With JS-safe command sequences, the left shift fits safely in u64. Host-originated values do not advance UI settlement. QueuedFeedback captures the contemporaneous packed value on the sole writer thread, so draining an old item cannot accidentally acknowledge newer queued work. This is deliberately a conservative live view, not a coherent whole-vector snapshot for state save/restore.

Reset cancellation is necessary: discarding an accepted seq1 while leaving settlement0 would leave the frontend forever below admitted1. Explicit cancellation now advances settlement while preserving old physical values and reports its cause/count. A later host value keeps that latest cause; a later applied UI command clears it. Cause is not cumulative cancellation history, and no document generation bump is introduced. Existing reset semantics and allocation safety remain intact. Ordinary snapshots use no admission guard: a held callback cannot block them, and reading cannot silence another block.

The two queue capacities form a small finite invariant: automation.len + reserved_ends never exceeds the configured capacity. Begin consumes one ordinary slot and reserves one; a matching End/detach converts its reservation into a real event, preserving that sum. A standalone value needs three free slots; an active value needs one. Runtime producer and automation deque are private and exclusively borrowed by apply, while the audio consumer only frees runtime space. Thus after prechecking both queues, a valid prepared physical value can enter runtime and all corresponding automation can be appended without an intervening producer filling either. Peek/ack makes external host acceptance an explicit future adapter duty. No current test claims actual CLAP output emission.

All new allocations, metadata/JSON/session work and string projection are off audio. Runtime queued items and feedback are Copy values; callback adds only fixed-bound iteration, scalar/settlement atomics and preallocated queue operations. It introduces no Arc clone/drop, mutex, serialization, I/O or waiting. The callback owner still must be stopped/returned before endpoint destruction by its adapter. Native Attachment validation rejects same-number identities from another actual session; normal commands originate from this controller's protocol admission. Alias metadata stays immutable because the controller exposes its session read-only. Later document/state replacement must preserve or atomically validate the public catalogue and introduce queue epochs; current code does not implement that future policy.

Architecture/readiness limits and simpler alternatives

The owned controller, one alias catalogue, reserved End count and per-parameter owner table are cohesive. A second optimistic scalar cache would create conflicting authority; locking or closing admission for reads would cause callback interference; a separate sequence/cause pair would permit torn reset metadata. The single packed atomic and existing queues solve these boundaries without another framework. The interval clamp is the smallest appropriate fix for endpoint roundoff. No additional extraction or production callback abstraction is justified by this tracer.

Inherited limitation retained precisely: RuntimeControl::activate holds ClosedAdmission and process returns zero-filled blocks while it remains held. A preempted control publication can therefore interrupt audible output. This candidate does not introduce that behavior and ordinary reads now avoid it. Existing gate coverage proves coherent admitted transition/closed silence, not uninterrupted native editor lifecycle audio. Task 3.3 and the full-beta goal must assess/stress editor destruction/recreation, admitted-job capture, native servicing and this publication boundary before claiming audio continuity. No full native scenario is marked satisfied or synchronized by this review.
