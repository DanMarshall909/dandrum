## Publication and queue semantics

Load reads/validates the entire bounded stream, derives the compatible scalar vector, checks next public generation, rechecks sample locality, prepares the native document and constructs the realtime candidate before acquiring callback admission. Existing session replacement supplies the transaction: accepted document/history replacement occurs while the runtime lease closes admission; lease publish offers the candidate and publishes restored scalar atomics, settlement0 and the accepted native revision as epoch before reopening admission. Structural journal/outcome reset follows existing valid external replacement semantics; invalid loads retain the prior journal and admitted native work.

RestoredScalars owns values+epoch together. UI event and feedback queues carry their originating epoch; only success advances epoch. The audio consumer skips old queued notes/parameters; its main consumer discards old feedback with a finite capacity bound. SPSC ownership remains unchanged; main never drains the audio event consumer. Reset cannot settle an old epoch command. New commands use the current epoch and normal sequence policy. Held gestures or outbound unacknowledged automation cause Busy; delivered Begin still reserves End until owner cleanup is host-acknowledged. A prior swapped runtime is reclaimed/destructed off audio before repeated activation; an unconsumed candidate remains Busy.

Save reads one coherent vector of applied physical scalar values using one SeqCst odd/even stamp. Audio and successful restore writers are serialized by the existing admission gate. Every participating stamp/data access is SeqCst; equal even stamps bracket a single global atomic order with no intervening scalar writer. Only the off-audio reader retries/yields. Audio adds fixed2 fetch_add operations and scalar stores, with no retry, lock, allocation, I/O or browser work. Stamp wrap limitation is explicit: a read cannot span2^63 complete write intervals. Reader liveness under a continuous writer is not bounded; ordinary UI parameter snapshots retain conservative settlement semantics and do not use this whole-state reader.

Structural publication still deliberately makes a callback arriving during the lease return silence. This core boundary does not claim native uninterrupted-audio acceptance; that existing limitation remains for later host continuity tests. No actual CLAP state/automation stream, WebView, native GUI, release binary, VST3, standalone or named DAW acceptance is claimed here.
