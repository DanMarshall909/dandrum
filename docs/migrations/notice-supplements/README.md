# Shared dependency notice sources

These unmodified upstream licence texts accompany five workspace-member crates
whose published archives declare a licence but omit their root text files:
jsonschema-regex and jsonschema-value 0.58.2, rhai_codegen 3.2.0, and
uuid-simd and vsimd 0.8.0.

`provenance.json` binds every package archive checksum, embedded VCS revision
and workspace path to the fetched upstream file URL, Git blob and SHA-256.
The SIMD licence retains its original absence of a trailing newline. The
archive omissions remain recorded. These are inputs for the private Linux
VST3 proof; bundle installation and complete product qualification remain open.
