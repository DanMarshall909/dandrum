# VST3 binding notice sources

These unmodified MIT and Apache texts come from the recorded source revision
`33f1859fbdcfa247c1fdd17d565cb5285860e4ce` of coupler-rs/vst3-rs, which is the
source identity published inside com-scrape-types 0.1.1. Its manifest at that
revision declares `MIT OR Apache-2.0`; the crate archive omits these root files.
`provenance.json` records their immutable URLs, Git blob and SHA-256 identities,
and their comparison with the notice files shipped in vst3 0.3.0.

This collection supplies traceable notice text for the private Linux proof.
The archive omission stays documented. It does not select a first-party licence
or authorize public plugin-binary redistribution. Complete bundle installation,
current-source dependencies and native qualification remain tasks 5.1/6.1.
