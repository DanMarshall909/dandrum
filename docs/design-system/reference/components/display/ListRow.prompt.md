ListRow lists layers, alternates, slices and presets; PropertyRow shows label/value settings and marks prepared (read-only) values with a lock; ParamLabel is a stacked label + value read-out.

```jsx
<ListRow label="Snare hard · alt 2" detail="vel 96–127" value="w 0.5" active selected />
<PropertyRow label="Voice limit" value="8" prepared />
<ParamLabel label="Pitch" value="1.000" unit="×" />
```
