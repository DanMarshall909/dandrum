ModIndicator names a modulation source and its depth in one chip; ModGlyph is the slot shape used on knobs, sliders and menus.

```jsx
<ModIndicator slot="A" source="Velocity" depth={0.25} active />
<ModIndicator host />
<ModGlyph slot="B" size={8} />
```

- Slots: A teal ●, B lilac ▲, C lime ■, D pink ◆. Host = blue plug glyph, never a slot.
